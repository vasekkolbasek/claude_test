# DECISIONS — «Неоновый Рой» / Neon Swarm

Журнал решений, принятых автономно (владелец недоступен). Формат: дата — решение — причина.

## Фаза 0 — требования и стек

- **Требования Яндекс Игр** успешно скачаны (WebFetch/curl, 2026-10-02) с `yandex.ru/dev/games/doc/ru/...` (requirements, sdk-about, sdk-game-events, sdk-events, sdk-adv, sdk-player, sdk-leaderboard, sdk-environment, languages-and-domains, local-launch). Реализация опирается на актуальную документацию, а не только на список из ТЗ.
- **Ручной переключатель языка — не делаем.** Документация (п. 2.14, 6.9) разрешает ручной выбор при наличии автоопределения, но он не обязателен. Язык берётся только из `ysdk.environment.i18n.lang` при старте. Фолбэк по документации: `be, kk, uk, uz → ru`, `tr → tr`, остальные → `en`.
- **Подключение SDK:** статический тег `<script src="/sdk.js"></script>` в `index.html` (как в документации для загрузки архивом). Локально dev/preview-сервер Vite и тестовый статический сервер отдают пустую заглушку `/sdk.js`, чтобы не было 404 в консоли; `YaGames` отсутствует → `LocalPlatform`. `YaGames.init()` обёрнут в таймаут 6 с.
- **Лидерборды:** используем новый API `ysdk.leaderboards.*` (старый `getLeaderboards()` устарел). `setScore` доступен только авторизованным — проверяем `isAvailableMethod` и авторизацию.
- **Рендер:** PixiJS 8.22, `preference: ['webgl', 'canvas']` (WebGPU не используем — менее стабилен на мобильных). Canvas-рендерер в Pixi 8.22 есть, отдельный фолбэк писать не нужно.
- **Glow без шейдеров:** свечение «запекается» в текстуры через Canvas2D `shadowBlur` при старте + аддитивное смешивание. Это в разы дешевле фильтров bloom на слабых Android и работает в Canvas-рендерере.
- **UI — DOM/CSS поверх canvas**, игровой мир — Pixi. Причина: чёткий текст, вёрстка под любые соотношения сторон, safe-area, локализация без перерисовки битмап-шрифтов. Цифры урона — Pixi BitmapText (динамический битмап-шрифт).
- **Шрифт:** Exo 2 (SIL OFL 1.1, пакет `@fontsource-variable/exo-2`), только подмножества latin, latin-ext (турецкий), cyrillic (~90 КБ), бандлится в сборку. Внешних шрифтов нет.
- **Симуляция отделена от рендера:** `src/game/**` — чистый TypeScript без DOM/Pixi. Это позволяет headless-симулятору баланса и юнит-тестам гонять настоящую игровую логику в Node.
- **TypeScript 5.9** (а не 7.x): typescript-eslint пока ориентирован на 5.x.
- **Playwright 1.63** при установленном Chromium ревизии 1194: запускаем с `executablePath: /opt/pw-browsers/chromium-1194/chrome-linux/chrome`, браузеры не скачиваем.

## Фазы 1–2 — ядро и платформа

- **Эмуляция рекламы** в `LocalPlatform` включается только в dev-сервере или с `?mock=1` (для тестов). Продакшн-сборка без SDK никогда не показывает ничего похожего на рекламу (требование 1.16 — без имитаций rewarded).
- **Interstitial** показывается только по нажатию «Продолжить» на экране результатов (естественная пауза, переход в меню), не чаще раза в 65 с (свой лимит поверх платформенного) и не в первых двух забегах (новичка не встречаем рекламой; стартовую рекламу платформа и так показывает сама).
- **GameplayAPI:** `start()` — забег идёт; `stop()` — пауза, меню, результаты, экран воскрешения, анимация смерти, реклама, скрытая вкладка/потеря фокуса, `game_api_pause`. Выбор карточки улучшения считается частью геймплея (это игровое действие, а не меню) — `stop` не вызывается, чтобы не дёргать разметку на каждом уровне.
- **Возврат во вкладку:** игра снимается с авто-паузы автоматически (как в ТЗ), если игрок не ставил паузу вручную; ручная пауза сохраняется.
- **Потеря фокуса окна (`blur`)** приравнена к скрытию вкладки: пауза + полное отключение звука (требование 1.3), `AudioContext.suspend()`.
- **Время для ежедневок** берётся из `ysdk.serverTime()` (защита от перевода часов), фолбэк — `Date.now()`.
- **Разрешение конфликтов сохранений:** при загрузке побеждает более свежая запись (`updatedAt`), при почти одновременных — с большим прогрессом; после входа в аккаунт (`resync`) — с большим прогрессом. Сброс прогресса пишется в облако немедленно.
- **Лидерборд:** техническое имя `endlessTime`, тип «время» (значение в миллисекундах) — лучшее время выживания в «Бесконечности». Отправка только для авторизованных (`setScore` требует авторизации); просмотр топа — без авторизации.
- **Название на турецком** оставлено «Neon Swarm» (единое латинское название для EN/TR, чтобы не нарушать п. 5.1 о совпадении названий в материалах).
- **Разблокировка персонажей:** каждый открывается либо за биты, либо автоматически при получении указанного достижения (Вольт — «Антивирус», Сапёр — «Чистая память», Охотник — «Мутация кода»).
- **Смоук-тесты** гоняются по распакованному `release/neon-swarm.zip`, раздаваемому из подпапки `/games/neon-swarm/` — это одновременно проверка относительных путей и самого архива.
- **Тестовые хуки** (`window.__ns`, бот) доступны только с `?test=1` или в dev-сборке.
