## План по файлам

```
index.html                 — /sdk.js, корневой div, загрузочный экран (inline CSS)
src/main.ts                — bootstrap: обработчики ошибок, платформа, i18n, сохранение, рендер, UI, ready()
src/config.ts              — константы (лидерборд, частота рекламы, лимиты)
src/core/                  — math (вектор, RNG), pool, spatial grid, emitter
src/data/                  — баланс: weapons, passives, enemies, waves, sectors, characters, workshop, achievements, rarity
src/game/                  — симуляция без DOM: World, Player, Enemy/Bullet/Gem, системы (spawn, weapons, AI, collisions, progression), Bot
src/render/                — Pixi: процедурные текстуры, GameView (синхронизация спрайтов), эффекты, фон
src/audio/                 — ZzFX-синтез SFX, процедурная музыка, AudioManager (громкость, mute-причины)
src/platform/              — Platform (интерфейс), YandexPlatform, LocalPlatform, detect, payments (заглушка)
src/meta/                  — сохранение (схема, версии, миграции, дебаунс), профиль, достижения, ежедневки
src/i18n/                  — ru, en, tr
src/ui/                    — DOM-экраны, HUD, карточки улучшений, джойстик, тосты, CSS
src/app/                   — Game: состояния (menu/run/results), причины пауз, оркестрация рекламы и GameplayAPI
scripts/                   — package.mjs (zip), simulate.ts (симулятор баланса), shots (скриншоты)
tests/unit, tests/e2e      — Vitest, Playwright
```

## Журнал

- **Фаза 0:** скачаны требования/SDK-доки, создан каркас (Vite + TS strict + Pixi 8 + ESLint + Vitest + Playwright), DECISIONS.md.

- **Фаза 1:** симуляция (World, 8 оружий, 13+ врагов, 3 мини-босса и финальный босс уже в коде), рендер Pixi (атлас с запечёнными glow-текстурами, ParticleContainer-слои, частицы, цифры урона, тряска, вспышки, hit-stop), DOM-UI (меню, выбор сектора, HUD, карточки улучшений, пауза, воскрешение, результаты, Мастерская, Персонажи, Кодекс, Достижения, Лидеры, Настройки, ежедневная награда), звук (ZzFX-синтез + процедурный синтвейв), платформа (Yandex/Local), сохранения с миграциями, i18n RU/EN/TR.

- **Фаза 2:** `npm run package` (чистый Node zip-writer + проверки архива), Vitest (44 теста: сохранения/миграции, карточки, волны, контент, i18n-паритет, мета), Playwright-смоук (мобильный 390×844 и десктоп 1920×1080) по распакованному zip из подпапки: загрузка без ошибок, ready, gameplay start/stop, пауза при скрытии вкладки, случайное управление, бот 60 с, результаты, ×2 за видео, все экраны меню.

- **Фаза 3:** весь контент проверен в игре через sandbox-хуки (`__ns.sandbox`): 8 оружий, 8 эволюций, 13 врагов, 3 мини-босса, Ядро Хаоса, 4 палитры секторов. Исправлен масштаб glow/колец (визуал ударной волны = хитбокс).
- **Фаза 4:** Мастерская (16 узлов, 4 ветки), 38 достижений с наградами, Кодекс (вирусы/оружие/эволюции/модули, рецепты), ежедневная награда (7-дневный цикл) и задание дня, «Бесконечность» + лидерборд, ненавязчивое предложение входа (результаты/настройки/лидеры), синхронизация достижений и разблокировок при старте.

- **Фаза 5 (в работе):** симулятор баланса `npm run sim` (карьеры бота, трассировка по минутам, длительность боссов), бенчмарк `npm run bench`, отладочный оверлей `?debug=1`, баланс подогнан под цели ТЗ (см. DECISIONS → Фаза 5), защитные таймауты рекламы, оверлей «Коснитесь, чтобы продолжить» при потере фокуса.

- **Фаза 5 (итог):** процедурные иконка/обложки (`?art=icon|cover`), генератор скриншотов `npm run shots` (RU/EN, 1080×1920 и 1920×1080, постановочные сцены через sandbox), читаемость плотных боёв (вспышка попадания — оверлей, меньше искр и цифр), блик босса, прямой старт первого забега для новичка, усиленный смоук-тест (60 с случайного ввода, game_api_pause, смерть → воскрешение за видео → смерть → результаты).

- **Фаза 6:** RELEASE.md (инструкция по консоли, тексты RU/EN/TR с проверкой длин, лидерборд, анкета модерации, чек-лист требований), видео геймплея (`npm run video`), обложка на витрину, замедленная победа, финальный прогон: typecheck/lint/44 юнит-теста/сборка/zip/6 смоук-тестов — всё зелёное.

- **Правка после релиза:** по просьбе владельца убран подзаголовок «Антивирус против роя» (EN/TR тоже) с обложек/баннеров и из логотипа в меню; ключ `game.tagline` удалён, арт и zip пересобраны.

- **Правки по отзыву (2):** тряска только на боссах; боссы на «поводке» + стрелка-указатель; спавн по курсу против бегства в одну сторону; нарастающий овертайм; приоритет автонаведения на босса; исправлен пропадающий со второго забега HUD; поэтапные разблокировки оружия/модулей/персонажей до 4-го сектора; пересмотр баланса симулятором (режимы `--land`, `--runner`). 50 юнит-тестов. Подробности — DECISIONS.md, последний раздел.

- **Правки по отзыву (3):** забег сокращён ×1,65 (Ядро на 6-й минуте, победа ≈ 7:25), меньше уровней за забег, баланс 8 оружий и эволюций по стенду `scripts/weapons-bench.ts` (эволюция бластера больше не доминирует), сектора и экономика под короткий забег; симулятор показывает урон по оружию. См. DECISIONS.md, раздел «Правки по отзыву (3)».

- **Правки по отзыву (4):** исправлены «залипающая» полоска босса, горячие клавиши под диалогами, уезжающая кнопка на итогах; поле на десктопе ≤ 2:1; явные надписи rewarded; аудит вёрстки всех экранов в 4 разрешениях; сверка с актуальными требованиями Яндекс Игр. 52 юнит-теста.

- **Правки по отзыву (5):** поэтапное открытие меню, интерфейс без прокрутки (листание страниц), враги по секторам + 4 новых вируса, Страж за 5 реклам, персонажи секторов за биты, сундук раз в 5 минут, пересмотр баланса. 57 юнит-тестов.

- **Правки по отзыву (6):** автоподгонка окон и итогов под экран (`fit.ts`), компактная плашка входа, крупные вкладки, аудит вёрстки `scripts/layout-audit.mjs` (14 размеров, режим Яндекса, наложения/обрезка) — чисто.

- **Правки по отзыву (7):** попадания вплотную (проверка по траектории), бластер −8–10 %, остальное оружие подтянуто, только вертикальная ориентация на телефонах, карточки разделов по комфортной ширине текста.

