## 2. Загрузка в консоль — по шагам

1. Откройте [Консоль Яндекс Игр](https://games.yandex.ru/console) → **Добавить приложение** → название «Неоновый Рой».
2. **Шаг 1. Технические параметры**
   - **Версия:** `1.0.0`.
   - **Архив:** `release/neon-swarm.zip`.
   - **Поддерживаемые платформы:** ✅ Десктоп, ✅ Мобильные (и планшеты). **ТВ — не выбирать** (меню рассчитано на касание/мышь, навигация стрелками по меню не реализована).
   - **Ориентация экрана на мобильных:** обязательно **«Вертикальная»** (портретная, только она). На телефонах и планшетах игра работает только вертикально: при повороте в альбомную ориентацию игра показывает экран «Поверните устройство вертикально», ставит забег на паузу и вызывает `GameplayAPI.stop()`; после возврата в портрет открывается меню паузы. Дополнительно игра пытается зафиксировать ориентацию через `screen.orientation.lock('portrait')` (браузеры разрешают это не везде, поэтому настройка в консоли обязательна). На десктопе ограничений нет (поле держится в пределах 2:1). Мобильные скриншоты — только `*-portrait-*`.
3. **Шаг 2. Метаданные**
   - **Игра переведена на:** русский, английский, турецкий.
   - **Возрастной рейтинг:** **6+** (абстрактные геометрические «вирусы», без крови и насилия над живыми существами).
   - **Категории (до двух):** «Экшен» и «Аркады» (альтернатива второй: «Стрелялки»).
   - **Теги:** рогалик, выживание, roguelite, bullet heaven, неон, орды врагов, автоатака, прокачка, эволюция оружия, боссы, одной рукой, вирусы, антивирус, аркада, таблица лидеров.
   - **Ключевые слова:** рогалик выживание, игра про вирусы, неоновая стрелялка, орды врагов, автострельба, прокачка оружия, эволюция оружия, антивирус игра, roguelite, survivors.
4. **Шаг 3. Дополнительные параметры**
   - ✅ **Игра использует облачные сохранения** (обязательно: прогресс хранится через `player.setData`, требование 1.11).
   - **Комментарий разработчика** (вставить текст из раздела 5 ниже).
5. **Шаг 4. Текстовые материалы** — тексты из раздела 3.
6. **Шаг 5. Визуальные материалы** — иконка, обложка (для RU — `cover-800x470-ru.png`, для EN и TR — `cover-800x470-en.png`; название «Neon Swarm» на латинице одинаково для EN/TR), по желанию обложка на витрину.
7. **Шаг 6. Материалы для продвижения** — горизонтальное видео (обязательно), вертикальное (по желанию), скриншоты: **минимум по 2** для каждой платформы.
8. **Реклама (вкладка «Реклама» / «Монетизация»)** — подключите монетизацию РСЯ. Игра вызывает только:
   - `ysdk.adv.showFullscreenAdv` — полноэкранный блок;
   - `ysdk.adv.showRewardedVideo` — видео с вознаграждением.
   Стики-баннер игрой не используется: опцию «Использовать API для показа sticky-баннера» включать не нужно (если включите стики-баннер «по умолчанию», он не перекрывает интерфейс — HUD учитывает safe-area, но визуально проверьте).
9. **Лидерборды (вкладка «Лидерборды»)** — создайте **один** лидерборд:

   | Поле | Значение |
   |---|---|
   | Техническое название | `endlessTime` (задано в `src/config.ts`; если меняете — поменяйте и там) |
   | [ru] Отображаемое название | Бесконечность — время выживания |
   | [en] | Endless — survival time |
   | [tr] | Sonsuzluk — hayatta kalma süresi |
   | Основной лидерборд | ✅ Да |
   | Тип | **time** (миллисекунды) |
   | Направление сортировки | **По убыванию** (больше время — выше место) |
   | Размер десятичной части | 0 |

10. **Инап-покупки — не подключать.** Игра их не использует. Модуль `src/platform/payments.ts` — изолированная заглушка (`PAYMENTS_ENABLED = false`) с описанием, как включить покупки позже.
11. Нажмите **Открыть с debug-панелью** (или добавьте `?debug-mode=16` к адресу черновика) и пройдите чек-лист из раздела 6 — индикаторы SDK, i18n и Game Ready должны быть зелёными.
12. **Отправить на модерацию.**

## 4. Анкета модерации — подсказки для ответов

| Вопрос | Ответ |
|---|---|
| Есть ли в игре реклама и где | Да, только через SDK Яндекс Игр. Полноэкранная — после экрана результатов забега при нажатии «Продолжить» (не чаще раза в 65 с, не в первых двух забегах). Видео с вознаграждением — только по нажатию кнопок с иконкой видео: воскрешение (1 раз за забег), «×2 биты» на экране результатов, переброс карточек улучшений (1 раз за уровень), бесплатный сундук в меню (раз в 5 минут), персонаж «Вольт» (5 просмотров). |

| Сбор персональных данных | Нет. |
| Внешние ссылки, сторонние покупки, сторонняя реклама | Нет. |
| Инап-покупки | Нет. |
| Язык | Определяется автоматически через `ysdk.environment.i18n.lang` при запуске (ru/en/tr; be/kk/uk/uz → ru, прочие → en). Ручного переключателя нет. |
| Управление | Касание/перетаскивание в любом месте экрана, WASD/стрелки, мышь. Esc/P — пауза. Не используются системные сочетания клавиш. |

## 5. Комментарий разработчика для модерации (вставить в черновик)

```
Игра полностью работает без авторизации; прогресс гостя хранится через player.setData и localStorage.
Реклама: полноэкранная — только после экрана результатов забега по нажатию «Продолжить» (не чаще раза в 65 с,
не в первых двух забегах); rewarded — только по кнопкам с иконкой видео (воскрешение, ×2 биты, переброс карт,
сундук в меню). Во время рекламы игра на паузе, звук отключён. Обрабатываются game_api_pause/game_api_resume,
GameplayAPI.start/stop, LoadingAPI.ready вызывается после показа главного меню.
Лидерборд: endlessTime (тип time) — режим «Бесконечность» открывается после первой победы над боссом.
Чтобы быстро увидеть всё содержимое на модерации: первый забег стартует сразу по кнопке «Играть»,
мини-боссы появляются на ~2:05 и ~4:05, финальный босс — на 6-й минуте.
```

## 7. Проверка локально с настоящим SDK (по желанию)

```bash
npm ci
npm run build
npx @yandex-games/sdk-dev-proxy -p dist --app-id=<ID черновика>   # откроет игру внутри yandex.ru/games с настоящим SDK
```
Dev-окружение без регистрации: добавьте `--dev-mode=true` — реклама будет заглушками SDK, сохранения в localStorage.

Полезные параметры адреса (безвредны в продакшене): `?debug=1` — FPS-оверлей; `?q=0|1|2` — фиксированное качество графики. Тестовые хуки (`window.__ns`, бот, sandbox) включаются только с `?test=1`.

## 8. Команды проекта

```bash
npm run dev        # dev-сервер (заглушка /sdk.js, эмуляция рекламы)
npm run typecheck  # TypeScript strict
npm run lint       # ESLint
npm run test       # Vitest: сохранения/миграции, карточки, волны, контент, локализация, мета
npm run build      # продакшн-сборка в dist/
npm run package    # release/neon-swarm.zip + проверки архива
npm run smoke      # Playwright: мобильный 390×844 и десктоп 1920×1080 по распакованному zip
npm run sim        # симулятор баланса (карьеры бота), --verbose --trace для подробностей
npm run bench      # CPU-бенчмарк симуляции на 300/600 врагах
npm run shots      # иконка, обложки и скриншоты в release/
npm run video      # MP4-видео геймплея в release/video (нужен ffmpeg с libx264)
npm run check      # всё сразу: typecheck → lint → test → build → package → smoke
```

## 9. Что нужно сделать руками

1. Создать черновик, загрузить архив и материалы (разделы 2–3).
2. Отметить **«Игра использует облачные сохранения»**.
3. Подключить **рекламу (РСЯ)** в консоли.
4. Создать лидерборд **`endlessTime`** (тип time, по убыванию, основной).
5. Пройти игру с **debug-панелью** (`?debug-mode=16`): индикаторы SDK / Game Ready / I18N зелёные, реклама показывается, звук выключается.
6. Проверить на реальном **Android среднего уровня** и **iPhone**: плавность (в настройках есть «Графика: Авто/Низкая/…»), поворот экрана, сворачивание во время забега, рекламу.
